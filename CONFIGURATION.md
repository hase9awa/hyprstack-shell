# Настройки Hyprstack

Файлы находятся в `${XDG_CONFIG_HOME:-$HOME/.config}`:

| Файл | Назначение |
| --- | --- |
| `hyprstack/shell.json` | Панели, темы, уведомления, погода и анимации |
| `hyprstack/layouts.json` | Scrolling / stacking |
| `hyprstack/workspaces.json` | Рабочие столы и распределение по мониторам |
| `hyprstack/effects.json` | Размытие и тени |
| `hyprstack/tiling.json` | Рамки, отступы, фокус по наведению и автопрокрутка |
| `hyprstack/hypr-vars.lua` | Приложения, горячие клавиши, оформление Hyprland |
| `hyprstack/monitors.lua` | Настройки экранов |
| `hyprstack/local.lua` | Дополнительные настройки Hyprland |
| `hyprstack/hypr-user.lua` | Служебное подключение Hyprstack; не редактировать |
| `hyprstack/monitors/<имя экрана>/shell.json` | Настройки отдельного монитора |

Настройки оболочки доступны в интерфейсе. `hypr-vars.lua` возвращает таблицу;
дополнительные вызовы `hl.config` и `hl.monitor` размещайте в `local.lua`
и `monitors.lua`.

**Обновление через `./update.sh` сохраняет пользовательские JSON-файлы,
`hypr-vars.lua`, `local.lua` и `monitors.lua`.** Не редактируйте стандартные файлы
в `hypr/`, включая `variables.lua` и `hyprland/keybinds.lua`, и служебный
`hyprstack/hypr-user.lua`: обновление перезаписывает их. Текущая цветовая схема
`hypr/scheme/current.lua` сохраняется.

## Экраны и клавиатура

Режим, расположение и масштаб экранов выбираются автоматически.
Переопределения задавайте в `monitors.lua`, включая HDR и VRR.
Яркость встроенного экрана управляется через системную подсветку,
внешнего — через DDC/CI.

Раскладка по умолчанию — `us`. Пример `local.lua` для двух языков:

```lua
hl.config({ input = { kb_layout = "us,ru", kb_options = "grp:alt_shift_toggle" } })
```

С Home Manager Lua-настройки также можно задать декларативно:

```nix
programs.hyprstack.extraConfig = ''
  hl.config({ input = { kb_layout = "us,ru", kb_options = "grp:alt_shift_toggle" } })
'';
```

Они применяются после `local.lua`; управляемый `hypr-user.lua` редактировать не нужно.

## Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| Super | Дашборд |
| Super + D | Запуск приложений |
| Super + O | Обзор окон и рабочих столов |
| Super + S | Дополнительное рабочее пространство; при включённой настройке — рабочие столы второго монитора |
| Super + Ctrl + Shift + M | Переключение scrolling / stacking |
| Super + H / L | Предыдущая / следующая колонка; на краю — соседний монитор |
| Super + J / K | Следующий / предыдущий рабочий стол |
| Super + Ctrl + F | Половина / полная ширина колонки |
| Super + Shift + стрелка | Перенос окна на соседний монитор |
| Super + Enter | Терминал kitty |
| Super + W | Браузер firefox |
| Super + E | Файловый менеджер через xdg-open |
| Super + Q | Закрыть окно |
| Super + F | Полный экран |
| Super + Alt + Space | Плавающее состояние окна |
| Alt + Tab / Alt + Shift + Tab | Переключение окон в stacking |
| Super + N | Центр уведомлений |
| Super + V | История буфера обмена |
| Super + Period | Emoji |
| Ctrl + Super + L | Блокировка |
| Ctrl + Alt + Delete | Меню сеанса |
| Super + Alt + K | Показать / скрыть панели |
| Print | Снимок монитора |
| Super + Shift + S | Снимок области |
| Ctrl + Alt + R | Начать / остановить запись экрана |
| Super + Alt + R | Запись со звуком |

Раздел **Сочетания клавиш** показывает действующие привязки с поиском.
Дополнительные привязки `hl.bind` размещайте в `local.lua` и задавайте им
`description` в третьем аргументе.
Переменные перечислены в [variables.lua](shell/assets/hyprland/config/variables.lua);
переопределяйте их в таблице `hypr-vars.lua`, например `kbTerminal = "SUPER + T"`
или `terminal = "foot"`.
Приложения для действий оболочки задаются отдельно в `shell.json`: `general.apps`.

В **Панели → Панель задач → Рабочие столы** включите **Наложение со второго
монитора по Super+S**. Поверх текущего рабочего стола откроются окна выбранного
стола второго экрана. Основной стол остаётся под наложением. **Super+1–0** и
сочетания следующего / предыдущего стола переключают столы внутри наложения.
Повторное **Super+S** закрывает слой и возвращает окна на исходные столы.
При перезагрузке конфигурации и подключении монитора окна также возвращаются
обратно; основной стол и распределение столов по экранам сохраняются.
Настройка сохраняется в `workspaces.json`: `secondary_on_special` (по умолчанию
`false`) и требует `per_monitor: true`. Имена мониторов и их наборы сохраняются,
поэтому второй экран можно выключить или отключить после первого подключения.
Поле `secondary_monitor` автоматически запоминает второй экран, чтобы старые
имена подключений не влияли на выбор его рабочих столов.

## Окна

**Super+H/L** на краю ленты переходит к окну на соседнем мониторе
в выбранном направлении. Пустые рабочие столы пропускаются, перехода по кругу нет.

**Super+Alt+Space** переключает плавающее состояние; размер и положение окна
сохраняются. Диалоги и просмотрщики Telegram/AyuGram остаются плавающими.

В stacking **Alt+Tab** выбирает окно; отпускание Alt или Enter активирует его,
Esc отменяет выбор. Свёрнутые окна также участвуют в переключении.

Подробнее о режимах — в [описании раскладки](shell/assets/hyprland/README.md).

## Жесты тачпада

| Жест | Действие |
| --- | --- |
| 3 пальца влево / вправо | Прокрутка колонок в scrolling |
| 3 пальца вверх / вниз | Следующий / предыдущий рабочий стол в scrolling |
| 4 пальца вверх | Открыть обзор |
| 4 пальца вниз | Подтвердить выбор и закрыть обзор |

В обзоре три пальца меняют выделение. В stacking работают только жесты обзора.
Вертикальная навигация ограничена рабочими столами текущего монитора.

Количество пальцев задаётся в таблице `hypr-vars.lua`:

```lua
return {
    gestureFingers = 3,          -- Колонки
    workspaceSwipeFingers = 3,   -- Рабочие столы
    gestureFingersMore = 4,      -- Обзор; отдельное количество пальцев
}
```

Добавьте нужные поля в существующую таблицу и выполните `hyprctl reload`.

## Язык и регион

**Язык и регион → Язык интерфейса**: русский, English или язык системы.
В `shell.json` это `general.language`: `"ru_RU"`, `"en_US"` или `""`.
Для отдельного запуска CLI: `HYPRSTACK_LANGUAGE=en_US hyprstack …`.

## Панель и масштаб

В **Панели → Панель задач → Видимость элементов** выберите **Все экраны**
или конкретный монитор. Индивидуальные параметры сохраняются в
`monitors/<имя>/shell.json` и имеют приоритет над общими.

Параметры оформления:

| Раздел настроек | Параметры в файлах |
| --- | --- |
| Обои и оформление → Масштаб интерфейса | `shell.json`: `appearance.scale`, 0.5–2.0 |
| Обои и оформление → Отступы между окнами | `tiling.json`: `gapsIn`, `gapsOut`, 0–100 px; Super+G переключает отступы |
| Обои и оформление → Скругление углов окон | `tiling.json`: `windowRounding`, 0–60 px |
| Обои и оформление → Тени | `effects.json`: `windowShadows`, `uiShadows`, `shadowSize`, `shadowOpacity` |
| Обои и оформление → Цвет рамки окна | `tiling.json`: `focusBorderColor`, оттенок текущей темы |
| Панели → Панель задач → Рабочие столы → Вид значков | Исходные цвета, тонировка или символы |

В тайлинге фокус по наведению включён по умолчанию. Отключить:
**Обои и оформление → Переключение окон при наведении в тайловом режиме**
(`tiling.json`: `focusOnHover`). При отключении у края скрытого окна появляется
кнопка перехода к нему. В stacking фокус меняется по нажатию.

**Обои и оформление → Прокрутка средней кнопкой мыши** (`tiling.json`: `autoscroll`):
удержите колёсико около 0,2 секунды и отпустите, затем двигайте мышь для прокрутки.
Esc, клик или вращение колёсика останавливают её. Короткий средний клик
и Ctrl+средняя кнопка сохраняют действие приложения.

## Темы и обои

**Обои и оформление → Цвета**: 18 встроенных тем, светлый / тёмный режим и акцент.
Список тем и источники — в [описании палитр](shell/assets/schemes/README.md).
**Обои → Обзор** выбирает изображение; до выбора используется однотонный фон.
Схема `dynamic` строит палитру по обоям.

```sh
hyprstack scheme list -n
hyprstack scheme list -a
hyprstack scheme set -n hyprstack-catppuccin -a blue -m dark
hyprstack wallpaper -f "$HOME/Pictures/Wallpapers/image.jpg"
hyprstack scheme set -n dynamic -m dark
```

Выбор сохраняется в состоянии Hyprstack и `hypr/scheme/current.lua`.
Пресеты можно создавать и импортировать через интерфейс.

**Обои и оформление → Цвета приложений** управляет синхронизацией палитры:

- GTK 2/3/4 и libadwaita; Qt 5/6 и KDE; Java Swing через GTK Look and Feel.
- Системное предпочтение светлого/тёмного режима для программ, использующих
  desktop portal: браузеров, Electron и других приложений.
- kitty, foot, Alacritty, WezTerm, Ghostty, Konsole, Xfce Terminal,
  GNOME Terminal, Tilix и XTerm. Для каждого терминала есть свой переключатель.
  Меняются фон, текст, курсор, выделение и 16 цветов ANSI. Неустановленные
  терминалы без конфигурации пропускаются.

Синхронизация включена по умолчанию и запускается при смене темы, режима,
акцента, динамической палитры и при старте шелла. Кнопка **Применить цвета сейчас**
позволяет повторить её, например после установки терминала.
Отключение общей или отдельной интеграции восстанавливает исходные параметры.
Посторонние настройки и сделанные в них изменения сохраняются.

Для Qt установите `qt5ct` и `qt6ct` (NixOS: `libsForQt5.qt5ct` и
`qt6Packages.qt6ct`). Для системного предпочтения нужны `gsettings`, схема
`org.gnome.desktop.interface` и backend desktop portal, который её читает,
например `xdg-desktop-portal-gtk`. Java требует включённой синхронизации GTK.
Для KDE-приложений выбирается общая схема Hyprstack, чтобы Dolphin и другие
программы не заменяли её стандартной Breeze. Для обновления открытых KDE-приложений
используйте `qt6ct-kde`: он передаёт схему в KColorScheme. Обычный `qt6ct` применяет
её при следующем запуске приложения. У бинарной сборки Throne с Qt в
`/opt/Throne` записи меню используют её совместимый GTK-плагин; для этого должны
быть включены обе интеграции, GTK и Qt. Изменения записей меню также обратимы.
Новые переменные оформления применяются к приложениям, запускаемым из шелла,
Hyprland и через D-Bus. Уже запущенные Java-программы нужно перезапустить.
Палитра передаётся открытым терминалам текущего сеанса через OSC; приложение
внутри терминала может переопределять эти цвета. Если программа не поддерживает
обновление оформления на лету, откройте её заново, в том числе после отключения
синхронизации. Приложения со своими темами, JavaFX и изолированные Flatpak/Snap
могут требовать выбора системной темы или дополнительной настройки.

В `hyprstack/shell.json` параметры находятся в `appearance.themeSync`:

| Поле | Назначение |
| --- | --- |
| `enabled` | Общий переключатель |
| `gtk`, `qt`, `java`, `system` | Отдельные интеграции приложений |
| `terminals`, `liveReload` | Палитры терминалов и передача цветов открытым окнам |
| `kitty`, `foot`, `alacritty`, `wezterm`, `ghostty`, `konsole`, `xfce4Terminal`, `gnomeTerminal`, `tilix`, `xterm` | Выбор терминалов |

Все поля логические, по умолчанию `true`. Например,
`"appearance": {"themeSync": {"enabled": false}}` отключает синхронизацию.
Журнал восстановления и последний отчёт находятся в
`${XDG_STATE_HOME:-~/.local/state}/hyprstack/theme-sync/`.
Не удаляйте журнал до отключения синхронизации. Ошибка одной интеграции
показывается в настройках и не отменяет смену темы шелла.

Форматы интеграций: [GTK](https://docs.gtk.org/gtk4/class.CssProvider.html),
[Qt/qt6ct](https://github.com/trialuser02/qt6ct),
[kitty](https://sw.kovidgoyal.net/kitty/conf/),
[Alacritty](https://alacritty.org/config-alacritty.html),
[Ghostty](https://ghostty.org/docs/config),
[WezTerm](https://wezterm.org/config/lua/config/colors.html).

## Расход ресурсов

Размытие, прозрачность и звуковой визуализатор по умолчанию отключены.
Для сборки визуализатора из исходников нужны libpipewire, aubio и libcava.
Добавьте `-DHYPRSTACK_AUDIO_VISUALIZER=ON` к команде CMake, пересоберите
и включите визуализатор в настройках.

## Погода

Включите **Язык и регион → Погода → Включить погоду**.
Местоположение: автоматически по IP или поиск города. Провайдеры:
**Open-Meteo** (7 дней) и **wttr.in** (3 дня); ключ API не нужен.

В `shell.json`: `services.weatherEnabled`, `services.weatherProvider`,
`services.weatherLocation` (пусто — IP; `latitude,longitude` — координаты).
Кнопка **Обновить погоду** запрашивает прогноз вручную.

## Запросы авторизации

Оболочка содержит агент Polkit. Отключите сторонний агент, чтобы избежать
конфликта регистрации.

## Блокировка

Используется системный PAM-сервис `hyprlock`. Другой сервис можно задать через
`HYPRSTACK_PAM_SERVICE` в окружении сеанса. Fingerprint/Howdy настраиваются отдельно.
