VPN на панели подключается одним нажатием. Добавлены раскладки US/RU (Alt+Shift), поддержка Hyprland 0.57.2 и установка непроверенных версий после подтверждения в Gist. Музыкальные приложения открываются без принудительного переноса на специальный рабочий стол.

Обновить: **Настройки → Обновления** или `hyprstack-update`.

Для старых версий:

```bash
curl -fsSL https://raw.githubusercontent.com/hase9awa/hyprstack-shell/main/update.sh | bash
```
