Hyprstack 1.5.1 добавляет быстрые меню VPN и уведомлений на панели задач.

- **VPN:** наведение открывает меню подключения и отключения. В нём доступны все добавленные соединения с прокруткой и флагами стран. Клик по самому значку открывает настройки и не переключает подключение.
- **Локации соединений:** флаг берётся из названия профиля либо определяется фоновым запросом через само соединение и кэшируется. Проверка не меняет активный VPN-туннель.
- **Уведомления:** в меню по наведению доступны «Не беспокоить», отметка прочитанного, очистка истории и открытие полного центра уведомлений. При открытии полного центра всплывающее меню закрывается.
- **Оформление:** новые меню используют общие анимации оболочки, включая плавное перетекание и брызги Goop. Их можно отдельно включать для каждого монитора в **Панели → Панель задач → Быстрые действия**.
- **Релизы:** убраны скриншоты страницы обновлений из описаний и вложений.

Обновить: **Настройки → Обновления** или `hyprstack-update`. Настройки пользователя сохраняются.

Для старых версий:

```bash
curl -fsSL https://raw.githubusercontent.com/hase9awa/hyprstack-shell/main/update.sh | bash
```
