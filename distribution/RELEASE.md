Обновление оболочки теперь доступно в **Настройки → Обновления**. Личные настройки сохраняются.

Для обновления старой версии:

```bash
curl -fsSL https://raw.githubusercontent.com/hase9awa/hyprstack-shell/main/update.sh | bash
```
