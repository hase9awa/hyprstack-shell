Hyprstack 1.5.5 исправляет ошибку завершения сеанса при установке обновлений в Hyprland с конфигурацией Lua. Апдейтер также сохраняет пользовательскую сборку Quickshell.

Для перехода с 1.5.4 или более ранней версии на Arch Linux и производных один раз выполните эту команду в терминале. Она загрузит исправленный апдейтер и попросит подтвердить выход из сеанса перед установкой.

```bash
curl -fsSL https://raw.githubusercontent.com/hase9awa/hyprstack-shell/main/update.sh | bash
```

После установки 1.5.5 дальнейшие обновления доступны через **Настройки → Обновления** или команду `hyprstack-update`.
