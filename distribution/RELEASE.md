В Hyprstack появились встроенные обновления.

- **Настройки → Обновления:** проверка версий, описание релиза, подготовка в фоне и установка.
- Автоматическая проверка стабильных релизов и небольшое уведомление о новой версии.
- Резервная копия, сохранение личных настроек и восстановление при ошибке установки.

Для обновления уже установленного Hyprstack выполните одну команду обычным пользователем:

```bash
curl -fsSL https://raw.githubusercontent.com/hase9awa/hyprstack-shell/main/update.sh | bash
```

Скрипт сам определит установленную версию, скачает релиз и соберёт обновление.
Перед установкой из графического сеанса он попросит сохранить работу и подтвердить выход
из Hyprland. После выхода установка продолжится в отдельной службе. Перед следующим
входом дождитесь её завершения; проверить статус из TTY можно командой
`hyprstack-update status`.

Начиная с этой версии для дальнейших обновлений достаточно:

```bash
hyprstack-update
```

Сборке нужны зависимости из [INSTALL.md](https://github.com/hase9awa/hyprstack-shell/blob/main/INSTALL.md).
На NixOS обновите вход `hyprstack` и пересоберите конфигурацию NixOS/Home Manager.
Подробности и откат: [MAINTENANCE.md](https://github.com/hase9awa/hyprstack-shell/blob/main/MAINTENANCE.md).
