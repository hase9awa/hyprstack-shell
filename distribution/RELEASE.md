Hyprstack 1.5.2 сокращает фоновую нагрузку оболочки и исправляет ошибки в интерфейсе.

- Панель задач объединяет обновления геометрии, а часы запускают таймер с секундным шагом только там, где отображаются секунды.
- Оболочка реже повторно загружает изображения и обновляет список приложений.
- Файловый диалог читает метаданные больших каталогов в фоне. Для отдельной папки можно включить общий порядок файлов и каталогов по дате изменения.
- Исправлена повторная авторизация Wi-Fi с новым паролем и обработка результатов подключения. Проверки состояния VPN выполняют меньше повторных запросов.
- Нативный модуль точнее отслеживает состояние окон при открытии просмотра медиа. Интерфейс, команда `hyprstack --version` и модуль Hyprland показывают номер сборки.

Обновить: **Настройки → Обновления** или `hyprstack-update`. Настройки пользователя сохраняются.

Для старых версий:

```bash
curl -fsSL https://raw.githubusercontent.com/hase9awa/hyprstack-shell/main/update.sh | bash
```
