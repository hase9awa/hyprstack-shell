Демонстрации цветов приложений и VPN собраны из настоящих снимков отдельного
сеанса Hyprland с публичной конфигурацией Hyprstack. В них добавлены подписи;
в конце VPN показаны увеличенные фрагменты меню и панели с выделением кнопок.
Снимки сменяются без имитации промежуточных состояний интерфейса.

Для демонстрации цветов использованы Dolphin (Qt 6), Thunar (GTK 3), небольшой
пример Java Swing с оформлением GTK и kitty. Приложения переоткрывались между
снимками палитр; GIF не демонстрирует обновление работающих приложений.
Java Swing требует перезапуска для применения оформления GTK.

VPN показан с учебными профилями VLESS, Trojan и Hysteria2 на зарезервированных
доменах `example.com`. Подключение к ним не выполнялось; личных профилей,
ключей и адресов в GIF нет. Внешний графический VPN-клиент не используется.
