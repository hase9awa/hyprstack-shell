<h1 align="center">Hyprstack</h1>

<p align="center">Два способа работать с окнами. Одно рабочее окружение для Hyprland.</p>

<p align="center">
  <a href="INSTALL.md">Установка</a> ·

Hyprstack — оболочка для Hyprland с прокручиваемым тайлингом и плавающими окнами.
Режимы переключаются одним сочетанием клавиш и сохраняют расположение окон.
Русский язык включён по умолчанию; английский и язык системы доступны в настройках.

## Возможности

- **Scrolling и stacking.** Лента колонок и плавающие окна с заголовками,
  сворачиванием и развёртыванием. В тайлинге фокус следует за курсором.
- **Обзор пространства.** Миниатюры окон и рабочих столов. В stacking — Alt+Tab
  с превью окон.
- **Панель задач.** Группировка, закрепление и превью приложений, рабочие столы,
  системный трей. Состав и расположение элементов настраиваются.
- **Поиск и запуск.** Приложения, калькулятор, буфер обмена, выбор темы и обоев.
- **Уведомления.** История, группировка, действия и режим «Не беспокоить».
- **Управление системой.** Звук, сеть, Bluetooth, снимки и запись экрана.
- **VPN.** VLESS/XHTTP/Reality, Trojan, VMess, Shadowsocks, Hysteria2 и TUIC
  через sing-box/Xray, импорт профилей и подписок, TUN и локальный прокси.
  Подключение из быстрых действий или с панели задач; настройки — в разделе «Сеть».
- **Дашборд.** Календарь, медиаплеер, состояние системы и погода.
- **Оформление.** 18 встроенных цветовых тем, светлый и тёмный режимы,
  акценты, синхронизация цветов GTK, Qt, Java Swing и популярных терминалов,
  масштаб интерфейса, отступы, скругления, прозрачность и анимации.
- **Блокировка и авторизация.** Экран блокировки с PAM и встроенный агент Polkit.

## Установка

- [Arch Linux / CachyOS / EndeavourOS / Manjaro](INSTALL.md#arch) — пакеты,
  сборка и конфигурация.
- [NixOS](INSTALL.nixos.md) — пакет и модули NixOS/Home Manager.

Требуются **Hyprland 0.56.2**, **Quickshell ≥ 0.3.1**, **Qt ≥ 6.9**.
После изменения ABI Hyprland нативный модуль нужно пересобрать.

[Обновление и восстановление](MAINTENANCE.md#обновление).

Пользовательские настройки храните в `~/.config/hyprstack/`: изменения стандартных
биндов — в `hypr-vars.lua`, дополнительные привязки и настройки — в `local.lua`,
настройки экранов — в `monitors.lua`. Эти файлы и настройки интерфейса сохраняются
при обновлении через `./update.sh`. Стандартные файлы в `~/.config/hypr/` и служебный
`hyprstack/hypr-user.lua` обновление перезаписывает; текущая цветовая схема сохраняется.
Подробнее — [настройки](CONFIGURATION.md).

## Первые действия

| Сочетание | Действие |
| --- | --- |
| `Super+Ctrl+Shift+M` | Переключить scrolling / stacking |
| `Super` | Открыть дашборд |
| `Super+D` | Запуск приложений |
| `Super+O` | Обзор окон и рабочих столов |
| `Super+Return` | Выбранный при установке терминал |
| `Super+W` | Выбранный при установке браузер |
| `Super+E` | Системный файловый менеджер · домашняя папка |
| `Ctrl+Alt+V` | Настройки звука · pavucontrol |
| `Super+H` / `Super+L` | Соседнее окно в scrolling |
| `Super+J` / `Super+K` | Соседний рабочий стол |
| `Super+Alt+Space` | Переключить плавающее состояние окна |
| `Alt+Tab` | Переключатель окон в stacking |
| `Super+Q` | Закрыть окно |
| `Ctrl+Super+L` | Заблокировать сеанс |

Полный список сочетаний с поиском — в настройках **Сочетания клавиш**.

На тачпаде в scrolling три пальца влево/вправо плавно прокручивают колонки,
вверх/вниз — рабочие столы. Четыре пальца вверх открывают обзор, вниз —
подтверждают выбор и закрывают его. [Настройка жестов](CONFIGURATION.md#жесты-тачпада).
